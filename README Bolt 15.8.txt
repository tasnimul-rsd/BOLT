BOLT 15.8 — PROJECT DUPLICATOR RESTORE

Developed by Tasnimul Hasan Malik
Designer & Animator

UPDATE
- Restored the working True Comp Duplicator.
- True Comp Duplicator now sits in its own compact box inside Project.
- Source comp is the selected Project comp, or the open comp when nothing is selected.
- Supports multiple copies and automatic sequential/versioned naming.
- Duplicate copies stay in the same Project folder as the source.
- Project tab refreshes the duplicate preview automatically.
- All existing Bolt 15.8 Smart Clean, Organize, Create, Render and Tools behavior is retained.
- Developer information remains intact.

USAGE
1. Select a composition in the Project panel, or open the composition.
2. Open Bolt > Project.
3. In True Comp Duplicator, choose Copies.
4. Review the generated name preview.
5. Click Duplicate.
